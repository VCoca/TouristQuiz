# TouristQuiz
TouristQuiz is a mobile Android application built with Kotlin and Jetpack Compose that combines tourism, maps, and gamification.

## Features
- Interactive tourist map
- Location-based quiz questions
- User authentication
- Leaderboard and scoring system
- User-generated content
- Modern UI built with Jetpack Compose

## Technologies Used
- Kotlin
- Jetpack Compose
- Android Studio
- Firebase Authentication
- Firebase Firestore
- Google Maps API
